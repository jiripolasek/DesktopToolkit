# WinUI Styles

Apply opt-in styles to built-in WinUI controls.

See the [package guide](src/README.md) for requirements, installation, and usage.

## Examples

Open **Pill search box** under **Styles** in the Desktop Toolkit Gallery to try the styled `AutoSuggestBox`.

## Development

- [src/](src/) contains the style resource dictionaries.
- [samples/](samples/) contains the gallery example.

See the [toolkit development guide](../../eng/README.md) for build prerequisites and shared commands.

# Searchable Flyouts

Add search to native command menus, virtualized item flyouts, and single-selection dropdowns.

See the [package guide](src/README.md) for requirements, installation, and usage.

## Examples

Open **Menus & Dropdowns** in the Desktop Toolkit Gallery for the [shared examples](samples/).
The standalone [development app](dev/) includes large collections and built-in WinUI controls for comparison.

## Development

- [src/](src/) contains the controls, templates, and package build logic.
- [tests/](tests/) contains the control checks for .NET 8, .NET 10, and .NET 11.
- [scripts/](scripts/) contains package, UI, and accessibility checks.
- The [component development notes](docs/development.md) cover how to run the app and checks, how the package
  is built, and how filtering, opening placement, and keyboard input work.

See the [toolkit development guide](../../eng/README.md) for build prerequisites and shared commands.

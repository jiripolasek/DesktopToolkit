# InfoLabel

Add a help tooltip beside a label, field, or heading.

See the [package guide](src/README.md) for requirements, installation, and usage.

## Examples

Open **Help Tooltips** in the Desktop Toolkit Gallery to try plain-text and formatted tooltips.

## Development

- [src/](src/) contains the control and its template.
- [samples/](samples/) contains the gallery examples.

See the [toolkit development guide](../../eng/README.md) for build prerequisites and shared commands.

# KeyVisual

[Package documentation](src/README.md)

Open the shared gallery and choose **KeyVisual**, or start the local development app from the repository root.

```powershell
dotnet run --project components/KeyVisual/dev -p:Platform=x64
```

The repository build runs KeyVisual's control checks on .NET 10 and .NET 11 and packs the component.
KeyVisual ships with the other packages in each [toolkit release](../../eng/RELEASING.md).

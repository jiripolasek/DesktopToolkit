# Date and Time Controls

Use CalendarDateRangePicker to select inclusive ranges with presets, blackout dates, and customizable flyout content.

See the [package guide](src/README.md) for requirements, installation, and usage.

## Examples

Open **Calendar date range picker** in the Desktop Toolkit Gallery to try the basic picker, custom flyout content,
date limits, and calendar styling. The **Web analytics** scenario uses the picker to scope reports.

## Development

- [src/](src/) contains the control, date range model, and templates.
- [samples/](samples/) contains the gallery examples.

See the [toolkit development guide](../../eng/README.md) for build prerequisites and shared commands.

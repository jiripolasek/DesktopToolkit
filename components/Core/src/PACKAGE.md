# JPSoftworks Desktop Toolkit Core

Provides the shared localization configuration for Desktop Toolkit components. Use `IStringResourceLoader` to supply strings from your app's own localization service. The controls handle their built-in RESW lookup.

The localized control packages include this package as a dependency. See the [localization guide](https://desktoptoolkit.jiripolasek.com/localization/) for catalog names, fallback behavior, and a custom loader example.

# Toast Windows

Show temporary in-app notifications with an acrylic backdrop and an optional action.

See the [package guide](src/README.md) for requirements, installation, and usage.

## Examples

Open **Toast Windows** in the Desktop Toolkit Gallery to show a toast, try an action, or compare
an explicit position with the Windows on-screen indicator setting.

## Development

- [src/](src/) contains the toast window and the window and backdrop helpers.
- [samples/](samples/) contains the gallery examples.

See the [toolkit development guide](../../eng/README.md) for build prerequisites and shared commands.

# Changelog

Notable changes to JPSoftworks Desktop Toolkit are recorded here.

## 0.1.0-preview.1

### Added

- The Controls bundle brings together DateRangePicker, InfoLabel, KeyVisual, Searchable Flyouts, and WinUI Styles.
- Charts and Toast Windows are available as separate package projects.
- The WinUI gallery includes live samples. The [documentation site](https://desktoptoolkit.jiripolasek.com/) includes package guides and an API reference.

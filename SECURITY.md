# Security Policy

## Supported Versions

Security fixes target the latest release of each Desktop Toolkit package.
For unreleased code, include the Git commit in your report.

## Reporting Security Issues

Please report vulnerabilities privately to the maintainers at
[support@jiripolasek.com](mailto:support@jiripolasek.com?subject=Desktop%20Toolkit%20Security%20Issue).
Include the affected package and version, the steps to reproduce the issue, and its impact.

## Preferred Languages

We prefer all communications to be in English.

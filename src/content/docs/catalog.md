Find a control by task. Each link opens its examples and package guide.

## Menus and commands

- [SearchableMenuFlyout](../components/searchable-flyouts/#native-commands). Filter native WinUI menu items, including submenu and context-menu commands.
- [SearchableItemsFlyout](../components/searchable-flyouts/#large-collections). Search a virtualized list of commands or items.

## Input and shortcuts

- [CalendarDateRangePicker](../components/date-time/#calendardaterangepicker). Pick a start and end date, apply a preset, or compare with another period.
- [SearchableDropDown](../components/searchable-flyouts/#single-selection). Filter a list and select a single item.
- [KeyVisual and ShortcutPresenter](../components/key-visual/#display-a-shortcut). Show keycaps and formatted shortcuts in menus, settings, or help.
- [ShortcutEditor](../components/key-visual/#edit-a-shortcut). Capture a shortcut and validate it or check for conflicts.

## Charts and dashboards

- [Line and scatter charts](../components/charts/#line-chart). Plot trends, ranges, and relationships, with options for annotations and inspection.
- [Bar and composition charts](../components/charts/#bar-chart). Compare values with bars, or show how parts add up with [doughnut and pie charts](../components/charts/#usage-meter-and-doughnut).
- [Hierarchies and flows](../components/charts/#treemap). Explore nested data with treemaps, [icicle charts](../components/charts/#icicle), and [sunbursts](../components/charts/#sunburst), or show movement and stages with [Sankey](../components/charts/#sankey-chart) and [funnel](../components/charts/#funnel-chart) charts.
- [Heatmaps](../components/charts/#heatmap) and [spider charts](../components/charts/#spider-chart). Compare patterns across a grid or several dimensions.
- [Live graphs and meters](../components/charts/#controls). Show live area graphs, radial gauges, and usage bars in compact dashboards.

## Help and notifications

- [InfoLabel](../components/info-label/). Put help beside a field using a native tooltip.
- [ToastWindow](../components/toasts/). Give brief in-app feedback with optional actions while preserving foreground focus.
- [Window and backdrop helpers](../components/toasts/#window-and-backdrop-helpers). Use a non-activating window or an acrylic backdrop that stays visually active.

See the [package index](../packages/) for the installable libraries behind these controls.
